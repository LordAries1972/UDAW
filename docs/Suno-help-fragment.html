Music Generation (Suno)

Generate finished music from a description or custom lyrics, then import the returned takes as editable WAV clips. Suno access is optional. UDAW connects to a third-party API provider, not suno.com directly - a suno.com subscription by itself is not an API key and does not unlock this feature.

By default the Suno panel is configured automatically: API type, base URL, model and callback are already filled in for the managed SunoAPI.org contract, all greyed out. The only thing you need to supply is your own API key.
  1. Get a managed API key: sign up at sunoapi.org (or another dashboard using the same apibox.erweima.ai contract), add credits, and copy the API key from its dashboard.
  2. Open the AI tab, choose Suno on the Provider row, paste the key into API key and press Save. UDAW stores it in the operating system's secure storage. Nothing else on the panel needs to change.
  3. Press Test. Success shows the provider's credit balance. HTTP errors, a website page instead of JSON, and invalid quota responses fail the test - most often a missing or wrong key. Check the AI log for the result. Test does not generate music.
  4. Enter a music description in Suno prompt, optionally select Instrumental, and press Generate. To supply lyrics, enable Custom lyrics/style, enter the lyrics in Prompt, and fill in Style / BPM and Title. In custom instrumental mode, style and title are required but lyrics may be blank.
  5. Watch the status bar or Jobs tab for submission, provider status, and take-by-take download and decoding. Generation runs in the background. Cancel stops local processing at the next cancellation check; an active network request can take up to its 30-second timeout. Remote work may continue and charges may still apply.
  6. The first finished take goes to the audio track selected when Generate was pressed, at the snapped playhead position captured then. Alternative takes go to separate lanes at the same position. If no valid selected track remains, UDAW creates a new lane. Clip insertion is undoable. Switching projects cancels/detaches the old job so it cannot import into the replacement project.

Model: the Model dropdown lists every value SunoAPI.org's managed /api/v1/generate endpoint actually accepts - V6, V6_WILD and V6_MINI are the current tier (V6 is the provider's own recommended default and UDAW's default selection); V5_5, V5, V4_5PLUS, V4_5ALL, V4_5 and V4 are listed as deprecated by the provider and marked accordingly - only pick one of those if your account is specifically still pinned to that older tier.

Advanced (self-hosted): check Advanced (self-hosted) to unlock the API type, base URL, model and callback fields and configure them by hand - for example to point at your own gcui-art/suno-api proxy fronting your own suno.com session, or a managed account with a non-default base URL or model. The self-hosted adapter uses /api/generate or /api/custom_generate, then /api/get?ids=...; a self-hosted proxy that does not require a key can leave the API key field blank, since its Suno session cookie stays on the proxy server, not in UDAW. Unchecking Advanced restores automatic configuration.

About the callback URL: the managed API's callBackUrl field is mandatory in its request schema, but UDAW never hosts a webhook - it polls /api/v1/generate/record-info for the result instead. In automatic configuration UDAW fills this with an inert placeholder on the reserved example.com domain that is never actually called; only fill in a real callback URL here if your own external tooling depends on receiving that provider's webhook independently of UDAW.

Completion and retries: UDAW waits for completed audio, not streaming previews, up to ten minutes total. The paid generation submission itself is sent exactly once and is never automatically retried, so a submit failure never risks a duplicate charge - after a timeout, cancellation or connection failure there, check the provider's task history before pressing Generate again. Once a generation is submitted, the background status poll that watches for it to finish is allowed one automatic retry if a single poll request drops due to a transient network hiccup (a dropped packet, a momentary DNS blip) - not on an actual error response from the provider - so a brief connectivity wobble part-way through a ten-minute wait doesn't abort an already-paid-for job.

Audio and timing: this integration downloads finished full-mix MP3 takes and converts them locally to WAV. Cached WAVs remain available if timeline import fails. BPM in the prompt is a suggestion; automatic grid warping, leading-silence removal, remote WAV conversion and stem-separation jobs are not included. The proxy's /api/concat endpoint joins extensions; it is not a stem-separation endpoint.

Provider selection and (in Advanced mode) URL, model and callback settings are saved when you Test or Generate. See the self-hosted API reference and the managed provider documentation for their server setup and account requirements.
