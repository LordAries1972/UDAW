Startup, recovery and recent projects

Settings has separate General, Colours and Diagnostics pages. Secure Storage, MP3, MP4, Graph, DSP, Supported SFX (formerly WAV), Advanced DSP and Scope are in Settings. Open Log from the main or popup menus. Colours controls backgrounds for clips with effects and fade-in/fade-out regions; choose coloured areas (default), curves, or both.

UDAW starts on the Project tab. It reopens the last successfully opened or saved project. If that project has an unclean-shutdown marker, UDAW automatically loads its newest available recovery candidate and marks recovered autosaved changes as unsaved. Recovery is limited to data already written to an autosave; it cannot restore edits made after the last snapshot. Missing or unreadable project data produces an error and leaves a new project available.

Project > File > Recent Projects lists the last ten distinct opened or saved projects, newest first. Reopening a project moves it to the top. The list survives restarts, and opening a recent entry uses the same recovery manager. Creating a new project clears the automatic last-project target until you save or open a named project.

The startup splash uses the saved visual theme from its first display. An animated circular activity indicator appears alongside the current startup stage and its progress bar. The animation continues while Windows startup work is busy; it does not imply a measured percentage.

UDAW saves its normal window dimensions and maximized state on close, then restores them on the next startup. Closing while minimized preserves the previous normal/maximized state. Restored dimensions are constrained to the current screen's working area.
